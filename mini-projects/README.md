# Mini-Projects

This directory stores small Laravel projects and project specifications used to apply architecture concepts end to end.

Mini-projects should be scoped enough to finish, but realistic enough to practice senior-level decisions.

Recommended structure:

```text
mini-projects/
  project-001-name/
    README.md
    SPEC.md
    NOTES.md
```

## Recommended Mini-Project Structure

```text
# Project 001: Project Name

## Goal

## Business Context

## Features

## Architecture Focus

## Technical Constraints

## Acceptance Criteria

## Lessons Applied

## Retrospective
```

## Rules

- Keep projects small and focused.
- Tie each project to roadmap milestones.
- Capture architectural decisions and trade-offs.
- Track completed mini-projects in `PROGRESS.md`.
