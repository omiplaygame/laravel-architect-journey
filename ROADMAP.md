# Roadmap

This roadmap tracks the long-term path toward becoming a Senior Laravel Architect.

Statuses:

- Not Started
- In Progress
- Completed

## Milestones

| Milestone | Status | Notes |
| --- | --- | --- |
| Foundation | Not Started | PHP, Composer, Laravel project structure, environment setup, conventions. |
| HTTP Lifecycle | Not Started | Request entry point, kernel, service providers, bootstrapping, lifecycle flow. |
| Routing | Completed | Route parameters, implicit and explicit model binding, route groups, named routes, throttling. |
| Controllers | Completed | Controller actions, Eloquent serialization, implicit binding, Request input, basic validation, Mass Assignment, HTTP response semantics, and a verified Product store endpoint. |
| Middleware | Not Started | Request filtering, cross-cutting concerns, auth, throttling, custom middleware. |
| Requests | In Progress | Form Requests, validation rules, authorization, input normalization. |
| Responses | Not Started | Redirects, JSON responses, resources, API consistency, error responses. |
| Views | Not Started | View composition, data passing, layout organization. |
| Blade | Not Started | Components, slots, directives, view models, maintainable templates. |
| Service Container | Not Started | Bindings, resolution, contextual binding, lifecycle, abstractions. |
| Dependency Injection | Not Started | Constructor injection, interface boundaries, testability, coupling control. |
| Configuration | Not Started | Config files, environment variables, caching, production configuration. |
| Database | Not Started | Migrations, transactions, indexes, constraints, schema design. |
| Query Builder | Not Started | Fluent queries, joins, aggregates, pagination, performance. |
| Eloquent | In Progress | Models, internal state, attributes, original snapshots, dirty checking, hydration, builders, and basic mass-assignment safeguards. |
| Relationships | Not Started | One-to-one, one-to-many, many-to-many, polymorphic relations, eager loading. |
| Authentication | Not Started | Guards, providers, sessions, tokens, starter kits, security basics. |
| Authorization | Not Started | Gates, policies, roles, permissions, domain authorization decisions. |
| Queues | Not Started | Jobs, workers, retries, failures, idempotency, queue architecture. |
| Events | Not Started | Events, listeners, subscribers, domain events, side effects. |
| Broadcasting | Not Started | Real-time events, channels, presence, authorization, frontend integration. |
| Caching | Not Started | Cache drivers, tags, invalidation, stampede prevention, performance strategy. |
| Testing | Not Started | Unit, feature, integration, database testing, factories, architecture tests. |
| Performance | Not Started | Profiling, N+1 queries, caching, queues, indexes, observability. |
| Architecture | Not Started | Layering, boundaries, services, actions, DTOs, modules, maintainability. |
| Deployment | Not Started | Server setup, CI/CD, config caching, migrations, zero-downtime concerns. |
| Clean Architecture | Not Started | Use cases, entities, interfaces, adapters, dependency direction. |
| DDD | Not Started | Ubiquitous language, aggregates, value objects, bounded contexts. |
| Scalability | Not Started | Horizontal scaling, async workloads, data growth, bottlenecks. |
| Microservices | Not Started | Service boundaries, communication, consistency, trade-offs, when not to split. |

## Update Rules

- Mark the current milestone as `In Progress` when lessons begin.
- Mark a milestone as `Completed` only when notes and practice are complete.
- Do not delete completed roadmap items.
- Add new milestones only when the learning path requires them.
