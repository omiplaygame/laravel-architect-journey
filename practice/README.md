# Practice

This directory stores exercises connected to lessons.

Every lesson should create practice. Practice should move from simple recall to realistic production judgment.

Recommended naming:

```text
lesson-001-topic-name.md
lesson-002-topic-name.md
```

## Recommended Practice Structure

```text
# Practice: Lesson 001 Topic Name

## Goal

## Exercises

## Refactoring Task

## Debugging Task

## Production Scenario

## Acceptance Criteria

## Reflection Questions
```

## Rules

- Practice should be concrete.
- Include acceptance criteria when possible.
- Prefer realistic Laravel scenarios.
- Include trade-off questions for senior-level thinking.
- Update `PROGRESS.md` after practice is completed.
