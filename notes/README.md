# Lesson Notes

This directory stores permanent lesson notes.

Lesson notes should be numbered, stable, and easy to scan. They should preserve learning history and should not be rewritten unless explicitly requested.

Recommended naming:

```text
lesson-001-topic-name.md
lesson-002-topic-name.md
lesson-003-topic-name.md
```

## Recommended Lesson Note Structure

```text
# Lesson 001: Topic Name

## Goal

## Key Concepts

## Explanation

## Examples

## Common Mistakes

## Production Considerations

## Senior Architect Notes

## Summary
```

## Rules

- Keep lesson numbers stable.
- Do not delete historical notes.
- Prefer incremental corrections with clear context.
- Link related practice files.
- Update `ROADMAP.md` and `PROGRESS.md` after adding a lesson.
