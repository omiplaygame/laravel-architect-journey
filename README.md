# Laravel Architect Journey

A long-term learning system for becoming a Senior Laravel Architect.

This repository is not a traditional application repository. It is a continuously maintained knowledge base for structured Laravel architecture learning, lesson notes, exercises, mini-projects, references, and senior-level engineering decisions.

## Purpose

The goal of this repository is to turn future ChatGPT lessons into durable learning artifacts. Each lesson should leave behind clear notes, practical exercises, roadmap progress, and evidence of growing architectural judgment.

This repository is designed so future updates can be driven by a small specification document instead of a long prompt. The permanent rules live in [.ai/codex.md](.ai/codex.md).

## Directory Overview

| Path | Purpose |
| --- | --- |
| `.ai/` | Permanent AI instructions, repository rules, and future update contracts. |
| `notes/` | Lesson notes organized by milestone and lesson number. |
| `practice/` | Exercises, drills, refactoring tasks, and implementation practice. |
| `mini-projects/` | Small Laravel projects used to apply architecture concepts end to end. |
| `cheatsheets/` | Compact references for commands, patterns, APIs, and decisions. |
| `resources/` | Curated links, reading lists, books, videos, talks, and documentation references. |
| `ROADMAP.md` | Long-term curriculum milestones and status tracking. |
| `PROGRESS.md` | Current learning state, completed lessons, acquired skills, and progress percentage. |

## Learning Workflow

1. A lesson is produced through ChatGPT or another guided learning session.
2. The lesson is converted into persistent repository artifacts.
3. Notes are added under `notes/` with stable numbering.
4. Practice tasks are added under `practice/`.
5. `ROADMAP.md` is updated to reflect milestone status.
6. `PROGRESS.md` is updated with acquired knowledge, senior skills, practice, and progress.
7. Changes are committed with a focused message.

## ChatGPT and Codex Cooperation

ChatGPT is used as the learning partner: it explains concepts, creates lesson specifications, asks questions, and helps deepen understanding.

Codex is used as the repository maintainer: it applies specifications, creates or updates files, preserves learning history, keeps formatting consistent, and commits focused changes.

Future lesson updates should provide only the new lesson specification. Codex should infer the correct files to create or update by following `.ai/codex.md`, `ROADMAP.md`, and `PROGRESS.md`.

## Repository Principles

- Preserve educational history.
- Prefer incremental changes over rewrites.
- Keep lesson numbering stable.
- Make every lesson practical.
- Track both knowledge and senior engineering skills.
- Keep Markdown readable and consistent.
- Treat roadmap and progress files as operational state.
- Keep commits focused and meaningful.

## Target Outcome

By the end of this journey, the repository should demonstrate not only Laravel knowledge, but also senior-level architectural thinking: trade-off analysis, maintainability, testing strategy, scalability, domain modeling, clean boundaries, deployment awareness, and production judgment.
